# 苹果镇的平安夜（The Christmas Eve of Apple Town）

> 一款温暖童话向 · **愿望侦探** · 鹅作剧式温暖互动 · 伪 3D · **单关卡深度版** 的剧情解谜叙事小游戏。

---

## 本地试玩：账号、API 与存档

已实现一个简易 Web 前端及本地数据库服务。需要 **Windows + Python 3.12 或以上**，无需安装第三方依赖。

在项目目录运行：

```powershell
python -E server.py
```

浏览器打开 **http://127.0.0.1:8000**。如端口被占用，可运行 `python -E server.py --port 8001`。关闭服务时按 `Ctrl+C`。`-E` 会忽略机器上可能设置错误的 Python 环境变量。

1. 创建账号或登录。重复账号（英文字母不区分大小写）、未注册账号、错误密码与两次密码不一致均有提示。密码采用随机盐与 PBKDF2 哈希；登录会话有效期为七天。
2. 登录后选择是否接入 API。选择接入，填写 **OpenAI 兼容基础地址、模型 ID、密钥**，实际完成一次对话请求验证后进入「本地模式」；暂不接入则进入「离线模式」。本地模式表示游戏服务和存档在本机运行，模型可以是远程服务或本机模型。
3. 支持的地址示例：`https://api.openai.com/v1`，本机服务可使用 `http://127.0.0.1:端口/v1`。程序会追加 `/chat/completions`，不要重复填写该路径。模型名称需填写提供商实际支持的模型 ID。接口需支持 `messages`、`max_tokens` 和非流式文本响应；不同协议的服务暂不支持。
4. 接入 API 后，西奥多对话会使用所配置模型和当前线索；其他内容保留预设逻辑。密钥只提交给本地服务，并通过 **Windows DPAPI** 加密落盘，不向前端回显。验证和对话会向你选择的提供商发送请求，可能产生费用。API 失败会保留存档并显示错误，可随时切换离线模式。
5. 简易试玩可探索八个地点、收集 C1–C8 线索、写日记、与西奥多对话，并在找到 C5 及至少五条线索后猜愿望。探索、收集、对话和结局操作立即自动保存；日记停止输入约 1.2 秒后自动保存，也可手动保存。未保存或请求未完成时，离开页面会触发浏览器提示。多个窗口发生存档冲突时会提示刷新，避免覆盖较新进度。
6. 每次进入页面自动恢复当前账号的模式、地点、线索、日记、最近 40 条对话和结局状态；退出后重新登录也会读档，并再次询问模式。账号之间的存档彼此隔离，两种模式共享该账号的进度。

数据库位于 `data/apple-town.sqlite3`，已被 Git 忽略。备份时先停止服务，再复制整个 `data` 文件夹；密钥需在同一 Windows 用户环境下解密，迁移电脑后应重新配置。账号和进度保存在这台电脑，不提供云同步。

文件结构：

```text
server.py        本地 HTTP 服务、账号、SQLite、API 适配与存档逻辑
web/index.html   登录、模式选择、API 配置及试玩页面
web/style.css    暖色纸张与雪夜钟楼风格、移动端布局
web/login.css    登录页冬日通行证与绘本布局
web/login-scene.js 登录页 Canvas 等距小镇、暖窗、立体钟楼与可暂停飘雪
web/app.js       前端交互、会话恢复与自动保存
test_server.py   使用临时数据库和模拟模型的接口集成验证
```

验证命令：`python -E -m unittest -v test_server`。测试不会读写正式账号数据库，也不调用付费外部模型。

登录页已采用 Canvas 2D 等距投影制作全屏伪 3D 小镇背景，登录卡片浮于场景之上：通过建筑的顶面与侧面、积雪、遮挡、软阴影和暖窗形成低模绘本效果，支持暂停飘雪，并适配窄屏与减少动态效果偏好。进入模式选择与游戏页后背景自动隐藏。无需下载外部模型、图片或渲染库，可离线显示。

当前试玩是账号与存档系统的功能原型；地点探索与结局为简化交互，尚未实现下文规划中的完整可玩 2.5D 关卡场景、机关小游戏和语气音。此次伪 3D 美术仅用于登录界面。服务仅监听本机地址，用于个人本地试玩。

### 版本取舍说明（重要）

本版做了一次**狠心的取舍：砍掉多章节，只留一关，把它做厚。** 留下的角色是守钟人**西奥多爷爷**；场景收进**一座钟楼和它脚下的一小块镇子**；**只有西奥多一个角色接 AI**，其余人都是预设对话；满镇的人都不说人话，只用**叽哩哇啦的语气音**表达情绪；另配一套**任务面板**，让玩家随时知道"现在能干嘛、还差哪块拼图"。

> **为什么单留这一关**：把六条愿望摆在一起比，西奥多这条最经得起反复咂摸 —— 别人是"思念一个人"，他是"思念一个没活成的自己"。它天然反套路：一般游戏让你"实现愿望"，这一关让你"先搞清楚愿望到底是什么"。钟不响不是坏了，是"没人再为它许愿，它就不愿意唱了"——这个反转把"修东西"变成了"懂一个人"。钟楼又是现成的立体玩具：楼下小广场、一楼大厅、机芯层、阁楼、钟顶平台，一层一个玩法，上下爬就是探索。

## 一句话概念与情感核心

**概念**：你扮演刚接任的圣诞老人（可自取名字），平安夜路过苹果镇的钟楼，发现大钟怎么敲都不响，一个叫托比的小孩蹲在楼下等了一晚。你顺着这条线往上爬，一层层翻开守钟人西奥多的过去，最后明白：**他要的不是离开，是被记得。**

**情感核心**：真正的祝福不是"给你想要的"，而是"我懂你没说出口的"。

**关卡情绪曲线**：好奇 → 好笑（摸索机关、碰出一堆小动静）→ 心里一软（翻到船票与海图）→ 鼻酸（他第一次认真讲月亮湾）→ 暖（钟声为两个人响起）。

> 一句话：这一晚，你要让一口不肯唱歌的老钟，重新开口 —— 办法不是修它，是读懂守了它一辈子的人。

## 类型与风格标签

- **游戏类型**：剧情解谜 · 叙事驱动 · 情景式冒险（探索 + 推理 + 情景小游戏）
- **风格基调**：**鹅作剧 × 英伦圣诞 × 伪 3D**
- **镜头**：鹅作剧式的**固定 / 半固定俯视镜头**，2.5D 等距。镜头基本不动，靠场景分层和遮挡制造纵深；走到哪一层，镜头温和地跟到哪一层，不晕。
- **画面**：干净的低多边形 + 柔和色块，描边极淡，雪景偏奶白，灯光偏蜂蜜黄。钟楼是画面主角 —— 尖顶、铜钟、爬藤、落雪，像一张会动的圣诞贺卡。
- **节奏**：没有倒计时催促，没有失败惩罚。你大可以把整个下午耗在机芯层拧齿轮玩，看它们一个个咬合。
- **幽默配比**：鹅作剧的"捣蛋"降级成"好奇的小手" —— 你能拧发条、碰响铃铛、把工具碰得叮当响、把西奥多的怀表拿起来端详。他会慢悠悠地回头看你一眼，不急不恼。笑点是"你在别人家里折腾"，不是"你伤害谁"。
- **无文字优先，但保留任务面板**：场景里尽量不打字，信息靠物件、表情、语气音传达；需要理清目标时，打开任务面板看一眼就够。
- **美术参考**：鹅作剧的干净低模与幽默镜头感 × 英伦乡村圣诞的暖；角色 Q 版圆润，各有"钥匙细节"。

**设计基调（重要约束）**

> 绝不死锁、关键节点不可错过、迷路有提示、猜错不惩罚 —— 打碎东西、送错"字面礼物"、直接问愿望，最多换来一句温柔的反馈。

## 世界观速览（背景设定）

### 苹果镇 —— 雪中的世外桃源

坐落在永远飘着软雪的山谷里，房子圆滚滚、暖洋洋，屋顶像撒了糖霜的姜饼屋。这里是传说中"圣诞老人也要专门绕路去看一眼"的地方 —— 不是因为热闹，而是因为每个人都真心想让别人开心。

但世外桃源里的人并非没有心事。他们的愿望藏在很深的地方：阁楼的旧木箱里、井底玩偶的口袋里、树下埋了三十年的铁皮盒子里、一年又一年"算了，不说了"的叹息里。苹果镇的人太温柔，温柔到不愿给别人添麻烦 —— 于是所有愿望都变成一粒粒安静躺着的种子。

### 传承：老圣诞老人退休了

执掌雪橇六十年的老圣诞老人把大了两号的红袍子、一本《愿望清单》、两个闹腾的小精灵和一只稳重的驯鹿，一起交给了新人。临别只留一句话：

> **"别急着送。先看懂，再送。看不懂的东西，送出去也是白送。"**

《愿望清单》里每页记着一位居民的名字，下面用金色墨水写的**不是"他要什么"，而是"他曾经在哪儿丢过什么""他心里最软的那块地方在哪里"**。而最后一页，被撕掉了。

### 今年的小麻烦

1. 雪橇的魔法铃铛掉了（没有它，雪橇飞不高，也找不到回家的路）；
2. 礼物袋被风刮开口子，礼物滚进了雪原；
3. 钟楼的大钟今年怎么敲都不响；
4. 以及新圣诞老人自己 —— 他连"该怎么送对一份礼物"都还没完全想明白。

## 核心设计支柱

1. **愿望侦探**：禁止直接问愿望，只能靠观察、打探、翻旧物、夜探把心愿挖出来。
2. **AI 极简边界**：本关**只有西奥多接大模型**，其余角色全部预设对话 —— 既有 AI 的"活"，又把成本、失控风险和配音量压到最低。
3. **叽哩哇啦语气音**：全员不说人话，用带情绪的音节说话（动物森友会 / 鹅作剧 / 模拟人生式），可爱、省事、天然不出戏。
4. **任务面板兜底**：无文字优先，但保留一张清爽的牛皮纸清单，让你始终清楚目标与拼图进度。
5. **轻柔无惩罚**：鹅作剧式高互动 + 永不卡关的温柔设计。

## 角色一览

### 玩家：新上任的圣诞老人（自取名字）

- 红袍子太大、帽球歪着；**不开口说人话**，也是叽哩哇啦，音色偏憨、偏暖。
- **能力**：拿 / 放 / 推 / 拉 / 拧 / 试穿 / 坐 / 远望 / 打开任务面板。

### 西奥多爷爷（Theodore）—— **本关唯一接 AI 的角色**

- **外形钥匙**：老花镜、怀表慢三分钟、说话慢悠悠每个字像被炉火煨过、爱坐钟顶看海。
- **性格**：笑眯眯、不急不躁，守钟如守老友；把一辈子的向往叠得整整齐齐压在箱底，不肯麻烦别人。

**AI 人格卡要点**

| 项目 | 内容 |
| --- | --- |
| 回避触发词 | 想要 / 愿望 / 礼物 / 送你 / 圣诞老人 / 想去海边吗 —— 踩中就用慢吞吞的话岔开，目光却飘向海的方向 |
| 好感来源 | 陪他看海、帮他给机芯上油、听他讲过去、把擦亮的相框给他看、穿水手外套出现在他面前 |
| 随口一提（好感够才漏） | "我像你这么大的时候啊，也想坐船去看看月亮湾……（笑）后来嘛，呼，就守着这钟了。" |
| 关键节点同步 | 当你翻到海图 / 船票 / 穿水手外套后，他会在钟顶主动开口，第一次认认真真讲三分钟月亮湾。这是本关最重的一场戏，**不可错过** —— 你不在场时，蒂皮会跑来拽你裤腿 |
| 闸门 | 他**永远不会**说"我要一本海图日记"，只会说"我一直……"。答案要你自己拼 |
| 语气音 | 低沉、缓慢、带一点气声的老人咕噜，句尾爱往下沉 |

### 托比（Toby）—— 预设对话 · 钩子担当

每晚蹲在楼下等钟声的小孩，心愿只有一句："奶奶的钟，什么时候唱歌呀？"

| 触发 | 字幕文本 | 情绪 |
| --- | --- | --- |
| 初见 | 爷爷说它会唱歌，可我等了好久好久…… | 期待 → 疑惑 |
| 你修好机芯后 | 它动了！可它怎么还是不唱呀？ | 疑惑 |
| 你试穿水手外套被西奥多看见 | （歪头）爷爷今天眼睛突然亮了一下…… | 好奇 |
| 结局钟声响起 | ……唱了！它真的唱了！ | 惊喜 → 开心 |
| 你也往墙根添一颗鹅卵石 | （愣一下）……嗯！谢谢！ | 意外 → 开心 |
| 你整晚只陪他坐 | （小声）爷爷今天好像很开心……谢谢你呀。 | 温柔、满足 |

> 作用：把"修钟"这件技术活，拴在"一个孩子想听歌"这件心事上。

### 海泽尔奶奶（Hazel）—— 预设对话 · 谜语教学

卖苹果干的守树人，不接 AI，只给几句点到为止的谜语。

| 触发 | 谜语 |
| --- | --- |
| 初见，你没头没脑问钟 | 急着修钟的人，修不好这口钟。 |
| 你翻完海图、还没懂 | 他不缺一双能走远的腿，缺一双肯回头看的眼睛。 |
| 你卡了很久 | 去问问月亮，别去问钟。 |
| 你翻到船票、还没拼完 | 月亮湾在海的那一头，可有些人的月亮湾，其实就在脚边。 |
| 终章，钟刚唱完 | 苹果干又红了一斤。 |

### 皮普 / 蒂皮 / 诺瓦 —— 预设对话 · 工具伙伴

- **皮普**：机芯层的小工匠，教你上油、对齿轮。口头禅"这样不对、要这样才对"。音色尖细、干脆、带点得意。
- **蒂皮**：阁楼与码头的小侦探，爱往箱子里钻，帮你够到你拿不到的东西。音色更快更飘，叽叽喳喳。
- **诺瓦**：驯鹿，驮你在钟楼区里快速移动、把你驮上高处。**不会说话**，只有温和的低鸣和响鼻。

### 客串（均为预设对话，各一两句）

- **莫莉奶奶**：路过时塞你一块饼干，"边吃边忙，别冻着"。提供一点暖意。
- **图书管理员**：打盹被你弄出的动静惊醒，迷迷糊糊给你指路到"月亮湾"那条旧档。

> **AI 边界（重要）**：本关只有西奥多接大模型，可自由对话、有好感与回避与同步节点；其余所有角色都是**写死的预设对话 + 语气音**，专门为这一条剧情服务。

## 故事线梗概

> 来源：《钟楼的歌》完整故事稿（第三人称 · 起因经过高潮结局）。以下为梗概与动机拆解。

### 动机拆解（先把"为什么"挖到底，免得写出来全是纸片人）

| 角色 | 核心动机 | 动机拆解 |
| --- | --- | --- |
| **西奥多 · 守钟人** | **被看见** | 他回避"你想要什么"不是客气，是一种温柔到近乎羞耻的自我折叠。十七岁那年填了水手训练班的报名表，字都歪了，压在钟楼阁楼的旧木箱里，等着走。后来父亲中风倒在床上，他把报名表塞回箱子，下楼接了老约翰的钟，一守就是五十三年。他不是没放下，是把放下这件事，叠进了每天敲钟的那一下里。怀表慢三分钟是**故意调的** —— 那年托比开始蹲墙根，他把表拨慢，是"给这个想奶奶的孩子多留一会儿"。水手外套的针脚不是他缝的，是当年隔壁裁缝阿姨缝的，他从来没穿过，只在每年水手节拿出来看一分钟 |
| **托比 · 蹲墙根的小孩** | **被回应** | 他爸妈不在身边、奶奶刚走，整个镇子唯一跟他聊奶奶的只有那口钟。奶奶生前每晚七点敲三下钟 —— "三下是我讲了三个故事，四下就是讲累了"。钟今年不响，托比蹲在墙根，不是等钟响，是**等奶奶再敲一下、再讲一个故事**。他每天带一颗鹅卵石，每颗对应奶奶讲过的一个故事；攒够二十一颗，他觉得奶奶就会把最后那个故事讲给他听 |
| **新圣诞老人 · 主角** | **第一次想真的送对一份礼物** | 他不是敷衍差事。他自己也是孤儿，从小跟在老圣诞老人身边，没跟任何一个镇上人真正聊过超过三句。他知道怎么把礼物塞进烟囱、怎么系红丝带，但不知道怎么让一个人**真的高兴**。这一关对他来说是第一次学习"人与人之间不只是送礼物那么简单" |
| **海泽尔奶奶 · 守树人** | **替老圣诞老人看好这个孩子** | 她不是谜语人。老圣诞老人退休前特意找过她，说"新来这孩子太急，你帮着泼泼冷水"。她的谜语不是故弄玄虚，是"别直接找答案，去找答案生长的地方"。她对西奥多特别关照，是因为老圣诞老人当年就是帮西奥多"被看见"的那个人 |

### 起因：新圣诞老人第一次碰壁

他踩着红袍子袖口走进苹果镇，怀里揣着只剩一行字"别急着送，先看懂"的愿望清单，打算从最显眼的西奥多开始。

第一次进钟楼是傍晚。西奥多坐在一楼书桌前，老花镜滑到鼻梁一半，手指摸着那只永远慢三分钟的怀表。他直接问："有什么愿望吗？我可以帮你。"

西奥多的手指停了一下，然后笑了 —— 那笑很客气，**像一扇刚推开一点就被身后的椅子腿刮到带关上的门**。"老头子要什么新东西呢……"他摸了摸怀表，"你刚到？累了吧？先喝口水。"

他没接"愿望"两个字。目光飘向窗外 —— 窗外是海的方向，他没说"海"，只是目光在那儿停了三秒，又收回来。

他去拉钟绳。大钟闷闷地"咔"了一声，像刚醒的熊，就是不肯唱。楼下传来托比的声音："它动了！可它怎么还是不唱呀？"站在钟绳旁边，他忽然觉得自己像个闯进别人家的小孩，拉亮了灯，却不知道为什么开灯。

### 经过：从旧物里拼出一个人

他开始漫无目的地翻：

- **码头**：旧木箱里翻出旧船票（"苹果镇—月亮湾"，1978 年，没画座位）与一本画满海船的老笔记本，每一页角落都写着"月亮湾"；
- **图书馆**：检索机吐出泛黄剪报 ——"苹果镇少年西奥多报名水手训练班，后因家事缺席"；
- **阁楼**：旧木箱里的旧海图（右下角被咖啡渍糊了半片，红箭头画得清清楚楚）、留声机（上发条放出跑调的老水手歌"月亮湾啊月亮湾，有只海鸥不回家"）、蒙尘的相框（擦亮一张，露出年轻时穿着水手服的西奥多）、衣柜里那件藏蓝色水手外套（肩线塌了，袖口缝了两针，针脚整齐，一看就不是水手本人缝的）。

他把外套套在红袍子外，脚步声下意识放轻，连呼吸都慢了一拍。西奥多抬头看了一眼 —— 那一眼很短，短到他以为看错了：老花镜后面，眼睛亮了一下，像有人从黑暗里划了一根火柴。

他忽然想起老圣诞老人的另一句话：**"愿望不是挂在嘴上的，是藏在你舍不得扔的东西里的。"**

西奥多舍不得扔的东西，全指向同一个方向：月亮湾。可他要的不是船票，不是去月亮湾 —— **他藏了一辈子的，不是一个地方，是一种"曾有过、没抓住、但还值得被记得"的感觉。**

### 高潮：他第一次说"月亮湾"

不是被什么刺激的 —— 他坐在一楼，听见阁楼里留声机的声音、听见有人翻他的旧木箱、听见有人把他压箱底的东西一件件拿出来、又一件件放回去。那些声音不吵，很轻，**像有人在翻阅他的记忆，但没拆穿**。

他把藤椅搬到钟顶，膝上盖着那条旧围巾，望海望了很久。新圣诞老人上来时，他没转头。

> "坐吧。你穿的那件……是以前留下的。呵，挺合身。"
> "我十七岁那年填了训练班的表，字都歪了，塞在阁楼的箱子里。后来我爸中风，躺了八年，我接了老约翰的钟，一守就到现在。"
> "月亮湾啊，我总觉得它就在那头，可它也不会自己来找我。其实啊 —— 我也没真怪谁。"

最后那句说得很轻，轻到差点没听见。但里面有五十三年：那个填歪了报名表的少年、那个把水手外套压箱底的守钟人、那个每天调慢怀表三分钟的老人。

### 结局：钟愿意唱了

他没有把船票递过去，也没有说"我带你去月亮湾"。他回到树屋，翻出老圣诞老人留下的那本空白海图日记，把阁楼看到的红箭头描进去，扉页上写了一句话 —— 不是华丽辞藻，就是老圣诞老人当年对西奥多说过的那句：**"你守钟守得好。"**

黄昏时他把日记放在钟顶藤椅的扶手上，转身下去了。过了一会儿，西奥多拿起日记，翻开，看到扉页那句话，手停在那里很久没动，然后轻轻叹了一口气 —— 不是难过，是那种"藏了很久的东西，终于有人看见了"的叹气。

他在楼下广场拉了一下钟绳。**这一次，大钟唱了。**

不是那种闷闷的"咔"，是带着余音、荡开去、能把整个镇子裹住的声音。托比仰起头，攥着那颗灰色的鹅卵石，忽然哭了，又忽然笑了 —— 他把奶奶临终前掉在墙根的最后一颗灰色鹅卵石也放上墙根，**二十一颗，齐了**。

钟继续唱。西奥多坐在藤椅上，手放在那本海图日记上，目光还望着海，但这次嘴角有一点翘起来 —— 不是那种客气的、扇一下就关上的门，是真的有一点翘。

> 钟唱完最后一声时，他看见钟顶上的西奥多，正摸着那只慢三分钟的怀表。**怀表还在慢三分钟 —— 他没调回去。因为三分钟，是给孩子留的余地；而今天，他终于给自己留了一点点。**

## 关卡设计

### 一、场景设计：钟楼区（一张小开放地图）

整个关卡就这一块地方，走路两分钟能绕一圈，但**每一层都塞满可交互**。从上到下：

#### 4.1 钟顶平台（最高层 · 情感落点）

一圈矮栏杆，能俯瞰整个雪中的镇子，远处是灰蓝色的海平线 —— 月亮湾就在那个方向。西奥多常在这儿：搬了把旧藤椅，坐着看海，膝盖上搭条毯子。

- **可交互**：黄铜望远镜（拿起可远眺码头与海面，望到月亮湾的轮廓；筒身刻着"月亮湾"三个字）、一排放大的鹅卵石（托比每天带一颗来的）、一面能敲响的小铜锣。
- **这里是结局送礼的地方**：黄昏、他看海时，把礼物放在他身边。

#### 4.2 阁楼（线索重地）

斜顶、积灰、一摞摞旧物。蒂皮最爱往这儿钻。

- **可交互**：旧木箱（翻开是一卷旧海图，红箭头指向"月亮湾"）、留声机（上发条，放出跑了调的老水手歌）、旧相框（擦亮一张，露出年轻时的西奥多穿着水手服站在船边）、衣柜（挂着压箱底的水手外套，**可试穿**）。
- **试穿水手外套是本关的关键互动之一**。

#### 4.3 机芯层（解谜核心）

满墙齿轮、摆锤、发条，大钟的"内脏"。皮普的地盘。

- **可交互**：一堆能拧的齿轮与发条（拧对了会一个个咬合转起来，拧错了只是空转，不会坏）、一罐机油、一根钟绳（拉一下，大钟闷闷地"咔"一声，就是不肯响）。
- **藏着一个轻柔的小谜题**：把停摆的机芯重新上油、对上齿轮。**但就算修好，钟也只是"能走了"，仍然"不肯唱"——这是设计的题眼。**

#### 4.4 一楼大厅（日常与回避）

炉火、一张旧书桌、西奥多的怀表搁在桌上。

- **可交互**：怀表（拿起来看，指针永远慢三分钟）、桌上的老花镜、一本翻开的旧笔记本（画满了各式各样的海船）、壁炉（能添柴、烤手）。

#### 4.5 楼下小广场（钩子与人群）

钟楼的门口，积雪、一盏路灯、一条长椅。托比整晚蹲在这儿，仰头看钟，墙根堆着他带来的一小堆鹅卵石。

- **可交互**：长椅（坐下会有 NPC 来搭话）、雪球（能捏着玩）、钟楼大门。

#### 4.6 镇子一隅（支撑线索的三个小点）

不展开成大世界，只留三个步行可达的小场景：

- **老码头一角**：一只旧木箱，里面是那张泛黄的旧船票 + 一本画满海船的老笔记本。
- **图书馆一角**：一个检索台，按"月亮湾"能调出一段旧航海志（旁证：少年西奥多报名水手训练班，后因家事缺席）。管理员是个爱打盹的老爷爷。
- **海泽尔的摊子**：杂货店角落，一杆小秤、旧报纸上摊着苹果干。她不接 AI，用几句预设的谜语给你指路。

> 你的"家"保留为钟楼区边上那间**小树屋**，墙上的挂画仍是**存档点**（铭牌显示存档信息），随时能回去存个档、睡一觉。

### 二、叽哩哇啦语气音效系统（不说人话）

**目标**：像动物森友会 / 鹅作剧 / 模拟人生那样，用一串没有语义、但有情绪的音节说话 —— 可爱、省事、还天然不出戏。这条同时解决了"配音贵、不有趣、出戏"三个问题。

**基本原理**：不配任何真实语言。每句话由一串短音节拼成（"咕噜""吧嗒""嘀哩""呜哇"之类），音高、语速、节奏随"角色音色 + 当前情绪"实时变化。屏幕上同步弹出气泡字幕（简短文字，给玩家读懂意思），声音只负责情绪和性格 —— **字幕是给人看的，叽哩哇啦是给心听的。**

**参数模型**：每个角色的声音 = 音色底（音域 / 音质 / 口癖音节）× 情绪调制（音高走向 / 语速 / 节奏 / 音量）。

**角色音色表**

| 角色 | 音域 | 音质 / 口癖 | 平时说话的感觉 |
| --- | --- | --- | --- |
| 西奥多 | 低 | 带气声、慢、爱拖尾音 | 慢悠悠的老人咕噜 |
| 托比 | 高 | 清亮、急促、爱蹦 | 叽叽喳喳的童声 |
| 海泽尔 | 中低 | 沙哑、气音多、几乎耳语 | 神秘的老奶奶低语 |
| 皮普 | 高尖 | 干脆、顿挫、有点冲 | 得理不饶人的小工匠 |
| 蒂皮 | 高 | 又快又飘、尾音打滑 | 停不下来的小话痨 |
| 玩家 | 中 | 憨、暖、圆润 | 老实人的嘟囔 |
| 诺瓦 | 低 | 不说话，只有低鸣与响鼻 | 温和的大个子 |

**情绪映射表**（套在任意音色上）

| 情绪 | 音高走向 | 语速 | 节奏 / 其他 |
| --- | --- | --- | --- |
| 开心 | 整体上扬，句尾跳一下 | 偏快 | 轻快、带笑 |
| 疑惑 | 句尾上挑 | 中 | 尾音拉长、停顿 |
| 难过 | 整体下沉 | 偏慢 | 拖长、音量变小 |
| 害羞 | 先小后更小 | 慢 | 音量渐弱、有点结巴 |
| 惊讶 | 突然拔高 | 快 | 短促、一两个音 |
| 得意 | 平稳偏高 | 中快 | 顿挫、翘尾音 |
| 温柔 | 平稳偏低 | 慢 | 轻、匀、像哄人 |

**两个例子**

- **西奥多 · 关键节点那句"我像你这么大的时候啊……"**：低音域、极慢、带气声，讲到"月亮湾"三个字时音高轻轻抬一下又落回去，尾音拖长 —— 光是听，就能听出"怀念"。
- **托比 · 结局"它真的唱了！"**：高音域、突然拔高、语速飞快、音节短促地蹦 —— 不用字幕也知道他开心坏了。

**实现管线（省事是关键）**

1. 每个角色录 / 合成一小套音节库（20–40 个基础音节即可，覆盖其音域）；
2. 运行时按"台词长度 + 情绪标签"从音节库里拼接，再按上表参数做音高 / 语速 / 节奏的实时调制；
3. 音节串与字幕气泡逐字 / 逐词对齐，嘴巴动画（Q 版只需张合）跟着音节走；
4. **同一套引擎服务所有角色**，只是换了音色底和参数 —— 加一个新角色，配一套音节库就行，不用重新配音。

### 三、任务面板系统

鹅作剧可以没文字，但你需要知道"现在能干嘛"。所以留一个清爽的任务面板，平时收着，想看随时展开。

**形态与调性**：外观是一张**牛皮纸圣诞清单**，红绳捆着，边角有烫金的冬青纹，跟树屋和钟楼的英伦乡村调子一致。两种状态：收起时只在屏幕角落留一枚别针小角标，显示当前主目标一行字；展开时是整页清单。

**信息结构（四块）**

| 模块 | 说明 | 示例 |
| --- | --- | --- |
| 当前目标 | 一句话，永远只有一条，告诉你现在最该做什么 | "去钟顶看看，西奥多好像有话要说。" |
| 线索碎片 | 你捡到的东西，一件件列着，标了来源 | 旧船票（码头）、旧海图（阁楼）、月亮湾航海志（图书馆）、水手外套（阁楼衣柜）、托比的鹅卵石（广场） |
| 愿望拼图 | 一个进度条 + 一句"还差几片"。攒够碎片能"猜愿望"，猜对锁定真相，猜错只给一句模糊提示，不惩罚 | "还差 1 片" |
| 待办与已完成 | 可选的小事清单，做完打勾，给你一点"今晚没白忙"的满足 | 帮机芯上油 / 擦亮相框 / 试穿水手外套 / 陪托比坐一会儿 |

**交互**

- 打开 / 收起一键切换；可以"**追踪**"某条线索，场景里对应方向会有一盏极淡的小灯提示（不硬指，留个寻找的余地）。
- 关键节点触发时，当前目标会自动更新，角落别针轻轻跳一下提醒你。

**字段（给程序看的）**

> 每条任务：`ID` / `标题` / `类型（主线·线索·待办）` / `状态（未接·进行·完成）` / `来源位置` / `关联碎片` / `触发条件` / `完成条件` / `是否可追踪`。

| 1 | **钟不响**（钩子） | 楼下小广场，黄昏落雪 | 看见托比蹲在墙根仰头看钟；拉一下钟绳，大钟只闷闷"咔"一声 | 主目标="弄清楚大钟为什么不唱"；待办新增"陪托比坐一会儿" |
| 2 | **初见西奥多**（回避） | 一楼大厅，炉火 | 跟他搭话；若直接问"你想要什么 / 是不是想去海边"，触发回避 | 线索区记下"他的目光望向海" |
| 3 | **摸索机芯**（鹅作剧式玩耍） | 机芯层 | 跟皮普学给齿轮上油、对发条；拧得满墙齿轮一个个咬合，拧错也不坏 | 主目标更新="钟能走了，可它为什么不唱？"；待办"给机芯上油"打勾 |
| 4 | **翻旧物**（线索铺开） | 阁楼、码头、图书馆，自由探索 | 翻出海图（C3）、船票与笔记本（C1/C2）、查航海志（C4）、擦亮相框（C6）、打开衣柜看到水手外套（C5） | 线索碎片一件件亮起；愿望拼图显示"还差 1 片" |
| 5 | **穿上水手外套**（情感钥匙） | 阁楼衣柜 → 走到西奥多面前 | 把那件旧水手外套套在红袍子外，再去找他 | 主目标="他好像愿意说了——去钟顶。" |
| 6 | **关键节点 · 月亮湾**（重头戏，不可错过） | 钟顶平台，他看海 | C5 上身 / 或集齐关键线索后，他状态改变、主动在钟顶等你；你不在场时蒂皮来拽你 | 愿望拼图可判定 |
| 7 | **愿望判定**（读懂，而非满足字面） | 愿望笔记本 | 猜成"送他一张船票 / 带他去月亮湾"→ 判定没读懂，只给一句模糊提示"他要的不是走"，不惩罚；猜成"希望有人记得他年轻时也想去远方"→ 判定通过 | 真相锁定 |
| 8 | **做礼物**（月亮湾海图日记） | 工坊（皮普帮忙） | 用海图、笔记本和一本新册子，做一本画着月亮湾海图的新日记，扉页写一句话（推荐："钟声替你看见过海。"） | 待办"做一本海图日记"→ 完成 |
| 9 | **送对礼**（时机与方式） | 钟顶平台，黄昏，他看海 | 不当面塞给他，趁他望着海，把日记轻轻放在他身边的藤椅上 / 毯子上 | —— |
| 10 | **钟声为两个人响起**（亮灯瞬间） | 钟顶 / 广场 | 你（或托比）再拉钟绳 —— 这一次，大钟唱了 | 主目标全部打勾；解锁隐藏待办"陪托比听完这一曲" |

**第 3 拍是题眼**：让玩家亲手发现"这不是个修理问题"。
**第 7 拍是本关的分水岭**：它在教玩家，最好的礼物未必是字面上的那个。
**收尾彩蛋**：回到树屋，把这一晚存进挂画；倒数日历翻开一格，露出老圣诞老人一句批注 —— "看不懂的东西，送出去也是白送——今天你读懂了一个。"

### 六、防卡关与轻柔失败

- **绝不死锁**：打碎东西、送错"字面礼物"都不会让线索消失，最多换来一句温柔的反馈。
- **关键节点不可错过**：你不在场，蒂皮来拽你；当晚系统也会把西奥多"安排"在你必经的路上。
- **迷路有提示**：卡关超过一会儿，海泽尔会用一句谜语点你（"去问问月亮，别去问钟"）；任务面板也能追踪线索方向。
- **猜错不惩罚**：愿望判错只给模糊提示，鼓励你再去看一眼，而不是重来。

### 七、彩蛋与重玩

- **托比的鹅卵石**：你也能往墙根添一颗，托比会愣一下，然后笑。
- **怀表的三分钟**：结局后怀表仍慢三分钟 —— 他还是要为孩子慢下来，这点不会变。
- **留声机全曲**：阁楼能集齐几张老唱片，凑齐一整支跑调水手歌。
- **第二种送法**：把日记塞进他壁炉边的圣诞袜，会触发另一段更安静的小剧场（他半夜悄悄起来看，看完放回袜子，并在袜子上多挂一颗自己缝的小铃铛）。
- **不送的结局**：你也可以整晚只陪他看海、听留声机，什么都不送 —— 钟照样会唱，因为"有人愿意陪他"，本身就被记住了。
- **码头的小铁罐**（故事稿彩蛋）：穿水手外套去码头，会在栈桥底下发现一个小铁罐，里面是西奥多十七岁那年写的一封信，收件人是"月亮湾"，没寄出去。

### 八、美术与音频参考

- **画面**：鹅作剧的干净低模与幽默镜头感 × 英伦乡村圣诞的暖；钟楼是视觉主角，奶白雪、蜂蜜黄灯、铜钟与爬藤。
- **角色**：Q 版圆润，各有钥匙细节（慢三分钟的怀表 / 水手外套 / 托比的鹅卵石 / 海泽尔的旧报纸与小秤）。
- **声音**：手风琴 + 木琴 + 铃铛打底；满镇的叽哩哇啦语气音当"人声"；**留声机的跑调水手歌、机芯齿轮的咔哒、大钟终于唱响的那一嗓子**，是三个最重要的听觉记忆点。
- **UI**：牛皮纸圣诞清单的任务面板；树屋挂画存档；糖果色圆角，像一本会动的童话绘本。

### 九、补充包素材（可直接对程序使用）

《单关卡补充包》已把三样东西做成可直接投产的形态：

| 素材 | 内容 | 形态 |
| --- | --- | --- |
| 预设 NPC 对话表 | 7 类角色、约 40 条对话 | 四列：触发条件 / 字幕文本 / 情绪标签 / 语气音参数 |
| 西奥多 AI 人格卡 | 拆成**卡 A · System Prompt**（喂给大模型一次）与**卡 B · 运行时卡**（每轮对话注入，动态刷新：好感度 / 当前线索状态 / 记忆摘要 / 当前位置） | 可直接注入 System Prompt |
| 场景剧本 | 六个地点（钟顶平台 / 阁楼 / 机芯层 / 一楼大厅 / 楼下小广场 / 码头·图书馆·海泽尔摊子） | 给关卡设计师与画师的参考，说的是"像什么"而非"有什么" |

**AI 人格卡的闸门规则（AI 必须遵守）**

1. 绝不直接说出愿望答案（"我想让谁记得我……"）；
2. 绝不主动给玩家送道具或线索（"阁楼里有海图"），最多说一句模糊的引导（"那口旧箱子，我塞了好多东西……忘了都"）；
3. 关键节点台词只在系统切状态后触发一次，触发后 AI 自己忘掉这段逻辑，回到常规对话。

## 技术实现要点

> 以下为设计文档给出的方向性说明，尚未最终定稿，将在技术设计阶段确认。

| 模块 | 方案 |
| --- | --- |
| AI 只给西奥多 | 人格卡（性格 / 回避词 / 好感 / 随口一提 / 关键节点 / 记忆摘要）注入大模型；回避与关键节点由**系统闸门**控制，AI 只负责把话和情绪说自然，**绝不泄底**。其余角色全部走预设对话表（ID / 触发 / 字幕文本 / 情绪标签 / 语气音参数），零 AI 成本 |
| 语气音管线 | 每角色一套音节库 + 音色参数；运行时按情绪标签拼接并实时调制音高 / 语速 / 节奏，与字幕气泡逐词对齐，嘴巴动画跟音节张合 |
| 伪 3D | Web 端 Three.js / PlayCanvas / Godot 导出 Web；低模圆润、暖光、雪粒子；固定 / 半固定等距镜头，分层与遮挡做纵深 |
| 任务面板 | 一套任务 / 线索数据结构（见"任务面板 · 字段"），UI 是牛皮纸清单，支持收起角标、展开、追踪、打勾 |
| 存档 | 树屋挂画为存档点，三幅画框对应三个存档位，铭牌实时渲染存档名 / 进度 / 镇上时间 / 存档时刻 |
| 可交互物理 | 沿用轻量"属性 + 规则"（材质 / 易碎 / 可拧 / 可穿 / 可上发条），保证每样东西碰了都有合乎直觉的回应，又低开销 |
