# 苹果镇 · 圣诞老人的木偶戏

一场发生在英伦小镇的圣诞冒险。白天戴上墨镜，做一位新邻居；夜里悄悄送出邀请，让一个孩子写在练习本里的故事，拥有自己的舞台。

## 故事梗概

圣诞老人暂住在苹果镇老橡树上的树屋里。为了不被孩子们认出来，他给自己取了一个化名，戴上旧墨镜，走进小镇。

在广场上，他遇见了九岁的诺拉。诺拉正在写一个关于圣诞老人的木偶戏：不管礼物有多难找，圣诞老人都要把它送到每个孩子手里。她有故事、有朋友，也画好了舞台草图，可社区中心的小舞台还空着。

你将扮演圣诞老人，在花店、面包房、图书馆和手作坊之间走动，收集材料，缝制木偶，搭起背景，挂好布帘和灯串，再烤一份圣诞点心。准备完成后，写一张邀请卡，趁夜从烟囱进入诺拉家，把邀请留在她的床头。

圣诞早晨，诺拉会推开社区中心的门。她写下的故事，将在父母、朋友和邻居面前开演。

## 玩法

### 探索小镇

从树屋醒来，为白天的自己填写化名。下梯子后，捡起公园小路上的墨镜，并手动戴上，才能走进小镇。

只有三个孩子会识破没戴墨镜的圣诞老人。他们会围上来讨礼物；重新戴上墨镜，就能脱身。成年人会把你当成普通的新邻居。

小镇有公园、广场、街巷，以及可以进入的花店、面包房、手作坊、图书馆、住家和社区中心。走近居民或物件，便能交谈、阅读或动手操作。与诺拉聊聊她的故事，就能开启舞台准备。

### 悄悄准备演出

五项准备可以按自己喜欢的顺序进行：

| 准备项目 | 玩法 |
| --- | --- |
| 三只木偶 | 收集袜子、线、棉花和纽扣，缝好一只圣诞老人木偶与两只儿童木偶，再摆到舞台后 |
| 舞台背景 | 翻看诺拉练习本里的草图，用纸箱与颜料制作纸板山和小屋 |
| 布帘 | 向花店借缎带与布卷，在台口挂好幕布 |
| 灯串 | 找到旧灯串，修好两处断线，再安装到舞台两侧 |
| 圣诞点心 | 分面团、压扁、放进烤盘和烤炉，取出饼干后摆到舞台前的桌上 |

小物件放在六格快捷栏里，同类材料可以堆叠。纸箱、布卷和灯串需要抱着搬，一次只能抱一件；抱着大件时走得更慢，也不能爬梯子。可以先把大件放在原地，稍后回来搬走。树屋里的礼物袋可以存放多余的小物件。

右侧的“圣诞清单”记录当前目标、准备情况、摘录的线索和自己的笔记。

### 制作邀请卡与夜潜

五项准备完成后，小镇进入黄昏。回到花店的包装桌，挑选封面、盖上圣诞老人印章，再写下演出地点与时间。邀请卡完成，夜幕便会降临。

从后院烟囱进入诺拉家，穿过一楼花店和楼梯走廊，抵达她的卧室。留意家长的视线，借柜台、布卷、窗帘和衣柜躲藏；响地板与碰倒的杯子会引来注意。

在床头柜旁保持安静，按住两秒放下邀请卡，再沿原路离开。若差点被发现，会回到当前房间入口，已经完成的准备和送卡进度仍会保留。

### 在小镇多待一会儿

演出之外，也可以浇花、翻书、喂鸟，投一枚硬币坐旋转木马，试穿居民的外套，或用花盆和彩旗装饰小镇。日常互动不要求赶进度，可以慢慢走、慢慢看。

树屋的三幅挂画分别对应三个存档位置，走近后可存入或读取。游戏也会自动保存进度。演出结束后，可以继续逛小镇、听居民的收尾对白，或重新开始。

### 操作方式

| 操作 | 按键或方式 |
| --- | --- |
| 移动 | WASD 或方向键 |
| 互动 | 走近后点击物件或互动按钮；E 使用最近的物件 |
| 戴上或摘下墨镜 | 点击快捷栏中的墨镜，或按对应栏位数字键 |
| 展开或收起清单 | Tab |
| 躲藏或离开藏身处 | H，或点击附近的藏身处 |
| 放下邀请卡 | 靠近床头柜，持续按住 E 或放卡按钮两秒 |
| 放下大件 | 点击携带提示里的“放下” |
| 存档与读档 | 走近树屋挂画，选择存入或读取 |
| 开启声音 | 点击登录页或游戏右上角的声音按钮 |

## 游戏风格

### 旧主机里的冬日小镇

画面采用固定斜俯视角，呈现 PS1 时代的低多边形与电子包浆质感：可见的硬面、轻微抖动、粗颗粒、有限色阶、像素纹理和暗角，让建筑与物件带着旧游戏的磨损感。

湿灰瓦、暗红砖、卡其色木头构成小镇的底色。白天没有积雪，石路与屋顶透着冬日的潮湿；黄昏逐渐染上暖色，夜里户外飘起像素雪，窗内仍亮着暖黄的灯。登录背景与游戏场景保持同样的视觉风格。

### 温柔、安静，也有一点顽皮

故事围绕一场悄悄准备的演出展开。缝歪的木偶、形状不齐的饼干和居民随口说的话，都属于小镇的日常。没有催促主线的倒计时，夜潜中的紧张也允许重新尝试。

角色对话配以无语义的短音，用音高、节奏与停顿表现不同人物的性格。白天的音乐轻巧，夜晚安静下来，圣诞早晨的演出重新热闹起来。

## 技术实现

### 前后端结构

项目使用 Python 标准库搭建本地 HTTP 服务，前端采用原生 JavaScript、HTML 和 CSS，无需第三方运行依赖。

| 模块 | 职责 |
| --- | --- |
| `server.py` | 登录注册、会话管理、模型连接、数据库读写和存档接口 |
| `game.py` | 场景与物件、任务推进、制作配方、库存、携带、昼夜及夜潜规则 |
| `web/app.js` | 登录界面、键鼠操作、清单、快捷栏、角色交谈和演出界面 |
| `web/scene.js` | 场景绘制、包浆效果、角色动画和声音生成 |
| `web/login-scene.js` | 登录页小镇背景 |
| `web/style.css`、`web/login.css` | 游戏与登录界面的布局和样式 |

前端负责接收操作和呈现画面，服务端校验互动距离、材料数量、携带限制与任务条件后更新进度。五条准备线分别记录完成状态，因此可以按不同顺序推进；昼夜变化、送卡和演出由任务状态衔接。

### 场景与包浆绘制

场景使用 Canvas 2D 绘制，将地面坐标投影为固定斜俯视画面。建筑、家具与角色由多边形构成，通过不同面的颜色和阴影表现体积，再按位置深度排序。

画面在 **320×240** 的内部画布上生成，以最近邻方式放大。绘制过程加入程序纹理与轻微顶点抖动，之后叠加 **4×4 有序抖色、色阶量化、颗粒、暗角和 8×8 宏块亮度偏移**，统一登录背景与游戏场景的质感。

当前素材由程序几何和纹理生成。纹理扭曲、压缩痕迹是视觉近似，并非真实 PS1 仿射贴图管线或 JPEG 编码；房间陈设、角色和演出动画仍可在后续素材阶段细化。

### 夜潜与声音

夜潜采用固定巡逻路线、扇形视野和障碍物遮挡判断。响地板与杯子会记录声源位置，使家长短暂转向；藏身状态、放卡计时与被发现后的返回位置由服务端维护。

声音通过 WebAudio 生成。角色对白使用不同音高、音色和节奏的无语义短音，不使用人声 TTS；背景音乐随白天、夜晚和演出切换。现阶段使用程序音色，后续可补充乐器采样与更细致的动作同步。

### 角色对话

只有诺拉接入动态模型，支持 OpenAI Chat Completions 兼容接口。玩家可以选择自己的模型，也可以使用离线预设对白。

人格提示限制诺拉的年龄、知识范围和说话方式。模型接收玩家化名、近期交谈和对话摘要，不接收舞台准备进度或玩家的真实身份。初见关键对白使用预设内容，连接失败或检测到明显越界回答时也会回退到预设对白，让主线可以继续。

### 账号与存档

账号、设置和进度存储在本机 SQLite 数据库中。密码采用带盐 PBKDF2 哈希，会话使用 HttpOnly、SameSite Cookie；API 密钥通过 Windows DPAPI 加密保存。

每次有效操作后自动保存，并更新存档版本号。多窗口提交旧版本进度时，服务端拒绝覆盖，前端重新读取最新存档。树屋的三幅挂画提供三个独立存档位置，按账号隔离，保存任务进度、化名、物品和装饰状态。
