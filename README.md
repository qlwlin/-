## 一句话概念

上一位圣诞老人退休了，新上任的圣诞老人（玩家）接过了传下来的红袍子和一本没写完的愿望清单。平安夜里，他不许直接问居民"你想要什么"——人人都笑呵呵地岔开话题。他只能靠着打探、观察、翻旧物、甚至溜进烟囱，把一个个藏得深深的、单纯美好的愿望挖出来，再亲手做成礼物送出去。

**核心情感**：真正的祝福，是"我懂你"。每一个愿望，都值得被温柔地认出。

## 类型与风格标签

- **游戏类型**：剧情解谜 · 叙事驱动 · 情景式冒险（探索 + 推理 + 情景小游戏）
- **视角**：2.5D 等距视角（伪 3D），低模圆润造型
- **风格关键词**：童话、温暖、童趣、解谜、世外桃源、成长
- **氛围基调**：暖黄灯火 + 飘雪粒子 + 星星光点；手风琴 + 木琴 + 铃铛声
- **叙事文风**：哈利波特式笔触 —— 第三人称有限视角、感官细节、英式幽默、点睛式人物刻画、轻伏笔
- **美术参考**：童话插画质感（《阿狸》）+ 温馨生活感（《星露谷物语》）+ 霍格莫德村的冬日烟火气

**设计基调（重要约束）**：

> 时间由天色、钟楼指针与飘雪轻柔推进，**不设倒计时、无压力**；
> 谜题与推理**永不惩罚玩家** —— 猜错愿望只给模糊提示，问错问题只降低信息效率，夜探被抓只会被笑呵呵地"拎出家门"。

## 三大核心支柱

### 支柱一：愿望侦探（玩法核心）

与传统"问 NPC 要什么"截然相反：**本作禁止直接问愿望**。

- **提问规则**：直接问愿望 → NPC 按性格回避，好感度略降（他们觉得"这不是圣诞老人该问的话"）；认真观察、聊生活、送关心 → 好感上升，并可能"随口"漏出关键的一句话。
- **每位居民至少 2–3 条独立线索链**，殊途同归。
- **《愿望笔记本》**：线索自动记入，可就地拼图；集齐后"猜测愿望"，猜对 → 愿望清晰可开工，猜错 → 只给"还差一片拼图"的模糊提示。
- **设计导向**：越"间接"的发现（烟囱、井底、时间胶囊），愿望拼得越快 —— 鼓励探索，而非蹲在 NPC 面前套话。

**愿望的六种发现途径**

| 途径 | 玩法 | 示例 |
| --- | --- | --- |
| 听来的 | 白天与别的 NPC 闲聊，打探目标人物的过去 | 罗斯默塔太太："莫莉啊，每年平安夜都多做一份苹果派放窗台……" |
| 烟囱潜入 | 夜里从某 NPC 家烟囱溜进去，翻找私人物品 | 西奥多爷爷家壁炉架上压着一张泛黄的旧船票 |
| 井底旧物 | 在老井里捞起破旧玩偶，口袋里缝着线索 | 破玩偶补丁里藏着一枚小铃铛和褪色的名字绣字 |
| 时间胶囊 | 在许愿树下挖出多年前埋下的铁皮盒子 | 巴纳比与弟弟的时光胶囊：铁皮青蛙 + 两行歪歪扭扭的约定 |
| 随口一提 | NPC 自然聊天中的"遗憾的是……" | 莱奥望着邮筒叹气："要是鸽子肯跑远一点就好了。" |
| 场景交互 | 检查可交互物：旧信、老照片、空座位、粘住的童话书 | 莫莉奶奶窗台上的第二副餐具，落了灰 |

### 支柱二：AI 对话与"回避机制"

- 每个 NPC 配置 **回避触发词**（如"想要 / 愿望 / 礼物 / 送你 / 圣诞老人"）与 **回避话术库**；
- 踩中触发词 → NPC 按性格回避（笑呵呵岔开 / 反问回来 / 假装没听见），并给出一个**开放式钩子**（说话时目光不自觉望向某处，即给玩家的提示）；
- 不惩罚"问错"，但削弱信息获取效率：直接问 ≠ 获得线索，只获得"他的目光望向某处"；
- **正确路径**：聊生活 → 积累好感 → 触发"随口一提"或解锁"可探索线索"（烟囱 / 井底 / 时间胶囊 / 场景）。
- **关键节点剧情同步**：玩家触达关键线索后，当晚该 NPC 状态改变 —— 出现在平时不去的地点，主动说出一段完整往事；每个 NPC 有 1–2 个同步节点，触发即锁定该段情感戏，**不可错过**。

### 支柱三：自由探索与场景交互

- **区域**（随剧情解锁）：苹果园 / 面包房 / 钟楼 / 杂货店 / 镇图书馆 / 老码头 / 雪原 / 圣诞小屋 / 老井 / 居民家中（夜探）。
- **能吃**：饼干、苹果派、星星糖、热可可 —— 回体力，且被 NPC 记住口味喜好；
- **能玩**：铁皮青蛙拧发条、雪人戴帽子、壁炉烤棉花糖、翻看杂货店商品；
- **能查**：旧信、老照片、日历、窗台、空座位、留言条；
- **能搜**：书架、抽屉、阁楼、井底、树洞、烟囱（线索主要来源）。
- **夜探模式（烟囱潜入）**：第三章后解锁（需先帮西奥多爷爷"唤醒钟"，获得"烟囱不会怕火"的信任）。夜间从烟囱滑入居民家中，房间 / 阁楼 / 壁炉架寻找线索，含**轻度潜行要素（非惩罚性）**。

## 发礼物闭环：从"读懂"到"做到"

1. **接愿望** —— 在《愿望笔记本》中解锁；
2. **找材料** —— 果园采摘 / 商店交换 / 雪原捡拾 / 工坊请皮普加工（四大来源）；
3. **做礼物** —— 圣诞小屋工坊合成，可自由装饰（丝带颜色会影响 NPC 的反馈彩蛋）；
4. **送对礼** —— 时机与方式同样重要：有的要"当面送"，有的要"悄悄放窗台"，有的要"趁他看海时放在他身边"。

送出后触发 **"亮灯瞬间"**：窗灯亮起、音乐变暖、许愿树多一颗光 —— 玩家能直观看到"祝福在回来"。

## 世界观速览

### 苹果镇 —— 雪中的世外桃源

坐落在永远飘着软雪的山谷里，房子圆滚滚、暖洋洋，屋顶像撒了糖霜的姜饼屋。这里是传说中"圣诞老人也要专门绕路去看一眼"的地方 —— 不是因为热闹，而是因为每个人都真心想让别人开心。

但世外桃源里的人并非没有心事。他们的愿望藏在很深的地方：阁楼的旧木箱里、井底玩偶的口袋里、树下埋了三十年的铁皮盒子里、一年又一年"算了，不说了"的叹息里。苹果镇的人太温柔，温柔到不愿给别人添麻烦 —— 于是所有愿望都变成一粒粒安静躺着的种子。

> 老圣诞老人看得见这些种子。他知道愿望是不需要说出口的 —— 它就在一个人的生活里，只要认真看，就能看见。

### 传承：老圣诞老人退休了

执掌雪橇六十年的老圣诞老人把大了两号的红袍子、一本《愿望清单》、两个闹腾的小精灵和一只稳重的驯鹿，一起交给了新人。临别只留一句话：

> "别急着送。先看懂，再送。看不懂的东西，送出去也是白送。"

《愿望清单》里每页记着一位居民的名字，下面用金色墨水写的**不是"他要什么"，而是"他曾经在哪儿丢过什么""他心里最软的那块地方在哪里"**。而最后一页，被撕掉了。

### 今年的小麻烦

1. 雪橇的魔法铃铛掉了（没有它，雪橇飞不高，也找不到回家的路）；
2. 礼物袋被风刮开口子，礼物滚进了雪原；
3. 钟楼的大钟今年怎么敲都不响；
4. 以及新圣诞老人自己 —— 他连"该怎么送对一份礼物"都还没完全想明白。

## 角色一览

### 玩家角色

**新上任的圣诞老人（尼古拉斯先生）**

- 身份：接替退休老圣诞老人的新人；红袍子是旧的、太大，帽子绒球永远歪着。
- 性格：真诚、有点笨拙、容易心软；最大的优点是**不会放弃"看懂一个人"**。
- 成长弧线：从"怕送错"的新人，成长为"愿意为一个人想很久"的真正的圣诞老人。
- **视觉化成长彩蛋**：每真正"看懂"一个愿望，袍子就合身一点、帽子绒球就正一点。

## 剧情章节大纲（一整晚 · 温暖推理）

**序章「黄昏抵达 & 传承仪式」**（~20min）
风雪中降临 → 伙伴集结 → 交接仪式（红袍子、愿望清单、那句嘱托）→ 教学（移动、交互、AI 对话、骑鹿）→ 初遇海泽尔奶奶获得谜语提示。
钩子：灯火亮起、钟声缺席、清单最后一页缺失。

**第一章「面包房的热气」**（~60min）— 莫莉奶奶的愿望（教程案例）
探索线索（第二副餐具 / 旧饼干模具）→ 关键发现（烟囱纸条或图书馆旧童话书配方插图）→ 笔记本猜中愿望 → 烤出第一炉"记忆苹果派"→ 同步剧情："她小时候最爱吃这个……她说长大也要学来着。"

**第二章「果园的星星果」**（~60min）— 巴纳比大叔 + 莱奥
巴纳比线：树下时光胶囊 → 铁皮青蛙与被水浸花的纸条 → 同步剧情 → 愿望判定：寄出今年最甜的星星果。
莱奥线：贺卡绑上小铃铛"让声音带路"→ 寄出。解锁雪原区域。

**第三章「钟楼的歌」**（~60min）— 西奥多爷爷 & 夜探解锁
缘起托比等钟声 → 码头旧船票 + 笔记 → 钟楼阁楼旧海图（月亮湾）→ 关键节点同步（他讲"月亮湾"三分钟）→ 礼物：一本画着月亮湾的新日记，扉页写"钟声替你看见过海"→ 钟声重响 → **解锁烟囱夜探**。

**第四章「六大愿望 · 自由探索黄金时段」**（~60–90min）— 罗斯默塔太太 + 黛西
罗斯默塔线：老井旧玩偶 → 铃铛找回 → 同步剧情 → 洗净补好，物归原主。
黛西线：她终于摸到诺瓦额头的红星星。
自由探索全面开放；海泽尔奶奶的苹果干颜色越来越红。

**终章「许愿树亮灯 & 最后一页」**（~25min）
所有已知愿望完成 → 许愿树亮起 → 清单最后一页仍然缺席 → **关键反转**：那页上写的是老圣诞老人自己的愿望 ——"请送一件礼物，给还会想起我的人。"
终局：玩家把"一瓶自己写的信 + 一颗星星果"留在老圣诞老人常坐的码头长椅上；钟声敲响零点，全镇灯亮，雪橇铃铛也被诺瓦找回。
结局蒙太奇：这晚的每个选择变成星星融进夜空；**新圣诞老人的红袍子，终于合身了**。

## 结局设计（温暖向多结局）

| 结局 | 触发条件 | 内容 |
| --- | --- | --- |
| 传承童话结局（Best） | 完成全部 6 个愿望 + 最后一件礼物送出 + 全员好感高 | 许愿树满花，全镇亮灯；老圣诞老人的愿望被接过；新圣诞老人正式接任，红袍合身，雪橇飞向星空 |
| 圆满结局（Good） | 完成大部分愿望 | 晚会圆满，树亮了，钟声响了；约定"明年还要来" |
| 温馨结局（Normal） | 完成一半愿望 | 晚会依旧温暖，树亮了几颗果子；没送完的礼物成为来年的种子 |
| 来年之约（隐藏） | 全员深入聊天 + 集齐全部线索 + 所有同步剧情触发 | 额外收尾：把写满名字的新笔记本放到老树下 ——"明年，我还会看懂你们更多一点。" |

> **结局没有失败**，只有"这一晚留下了多少温暖"。

## 技术方案（初步 · 待定）

> 以下为设计大纲第十节给出的**方向性说明**，尚未最终定稿，将在技术设计阶段确认。

| 模块 | 初步方案 |
| --- | --- |
| 渲染 / 引擎 | Web 端优先：Three.js / PlayCanvas / Godot 导出 Web；低模圆润，暖色灯光 + 雪粒子 |
| 对话接口 | 接入大模型 API（DeepSeek / 豆包 / 通义等），每 NPC 加载"人格卡 + 记忆摘要 + 好感度 + 回避词表 + 可谈话题" |
| 回避系统实现 | 人格卡内嵌"回避触发词 → 回避话术库 → 开放式钩子"规则；系统检测触发词后劫持回复模板，AI 只负责"开放性钩子"的自然表达 |
| NPC 行为 | 轻量状态机 + 时间表驱动；AI 仅接管对话决策，行为遵循日程 |
| 夜探状态 | 居民"在家 / 不在家 / 已睡"三态由日程表控制；潜入时不触发正面对话，线索由场景交互提供 |
| 存档结构 | 好感度表、愿望完成表、线索碎片表、已送礼物、记忆摘要（压缩存储） |
| 安全与防滥用 | 对话基础过滤；关键线索只在"同步节点"解锁，AI 不负责泄底 |
